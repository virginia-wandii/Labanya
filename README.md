# Pizza Hut Website
## About the project
The pizza Hut website is a beginner-friendly web development project inspired by pizza-hut.It provides a simple and attractive interface where users
can explore pizza options,view items and prices,and find contact information.

## Project Objectives
.create a responsive and user-friendly website
.Practice HTML for structuring web pages
.Use Css to style and improve the website's apprearance
.Use JavaScript to add interactive features 
.Organise website files into a clear project structure

## Features
.Home Page
.Menu Page
.Shop page
.Contact Page
.Navigation bar

## Technologies used
HTML
CSS
JavaScript
Git and GitHub
## How to run the project
.clone the repository
.open the project folder in visual studio code
.open index.html in your browser,or use the live Server extension
.Explore the different pages using the nav bar
